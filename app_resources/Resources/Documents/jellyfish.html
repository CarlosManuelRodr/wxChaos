Jellyfish

A Julia-style escape-time fractal using a fractional power.

Formula

\(z_{n+1}=z_n^{3/2}+k\), with default \(k=-0.2+0i\). Each pixel supplies \(z_0\), and escape is detected when \(|z_n|>2\).

Background

This is an exploratory Julia-family variant rather than a classical named set. The fractional power makes the map multi-valued in the complex plane; the implementation uses the principal branch supplied by the complex power function. The result often grows soft radial arms and tendrils, which explains the Jellyfish name.

wxChaos capabilities

  • High-precision rendering.
  • Julia constant editing, orbit display, smooth coloring, and orbit traps.
  • Algorithms: escape time, Gaussian integer, escape angle, triangle inequality.
