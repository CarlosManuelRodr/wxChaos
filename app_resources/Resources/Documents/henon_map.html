Henon Map

The Henon map is a two-dimensional chaotic map. wxChaos plots the orbit generated from an initial point and marks every visited pixel in the current view.

Each iteration uses

xn+1 = yn + 1 - αxn2
yn+1 = βxn

The default parameters are α = 1.4, β = 0.3, x0 = 0.5, and y0 = 0.2. Because this renderer plots a single orbit rather than testing every pixel independently, it uses one render thread and redraws the whole image when the view or options change.
