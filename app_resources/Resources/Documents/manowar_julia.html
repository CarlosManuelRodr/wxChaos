Manowar Julia

A Julia set with a short-term memory.

\(z_0=m_0=p,\quad z_{n+1}=z_n^2+m_n+k,\quad m_{n+1}=z_n\)

Here the parameter is fixed and each pixel chooses the starting value. Because the Manowar rule remembers the previous step, the orbit can feel less like a point jumping and more like a point dragging a thread.

This fractal was created by Scott Taylor and Lee Skinner for FractInt.

Mathematical notes

Fixed parameter, remembered past

The Manowar Julia rule fixes \(k\). For each pixel with complex coordinate \(p\), wxChaos starts with \(z_0=m_0=p\), then iterates \(z_{n+1}=z_n^2+m_n+k\). The memory value \(m_n\) is updated from the previous \(z\). Unlike a standard Julia set, the visible fate of a point depends on a two-value state.

Galería de fractales

Julia de Manowar

Un conjunto de Julia con memoria a corto plazo.

\(z_0=m_0=p,\quad z_{n+1}=z_n^2+m_n+k,\quad m_{n+1}=z_n\)

Aquí el parámetro permanece fijo y cada píxel elige el valor inicial. Como la regla de Manowar recuerda el paso anterior, la órbita puede sentirse menos como un punto que salta y más como un punto que arrastra un hilo.

Este fractal fue creado por Scott Taylor y Lee Skinner para FractInt.

Notas matemáticas

Parámetro fijo, pasado recordado

La regla Julia de Manowar fija \(k\). Para cada píxel con coordenada compleja \(p\), wxChaos comienza con \(z_0=m_0=p\) y después itera \(z_{n+1}=z_n^2+m_n+k\). El valor de memoria \(m_n\) se actualiza a partir del valor anterior de \(z\). A diferencia de un conjunto de Julia estándar, el destino visible de un punto depende de un estado formado por dos valores.
