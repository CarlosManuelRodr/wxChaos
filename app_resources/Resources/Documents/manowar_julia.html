Manowar Julia

The fixed-parameter dynamical plane for the Manowar recurrence.

Formula

Each pixel supplies \(z_0\), the constant \(k\) is fixed, and \(m_0=z_0\). wxChaos iterates \(z_{n+1}=z_n^2+m_n+k\), \(m_{n+1}=z_n\), with escape at \(|z_n|>2\).

Background

This is to Manowar what a Julia set is to Mandelbrot: instead of asking which parameters \(c\) produce bounded behavior, it fixes one parameter \(k\) and studies the starting-value plane.

wxChaos capabilities

  • High-precision rendering, Julia constant editing, and orbit display.
  • Smooth coloring and orbit traps.
  • Algorithms: escape time, Gaussian integer, escape angle, triangle inequality.
