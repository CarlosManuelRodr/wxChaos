Logistic Map

The logistic map is a one-dimensional recurrence that shows how a simple feedback rule can move from stable behavior into period doubling and chaos:

xn+1 = axn (1-xn)

wxChaos plots the parameter a horizontally. For each column it starts from the configured seed, optionally discards an initial settling pass, then plots the remaining iterates. The restored default view follows the original wxChaos 1.2.0 range, with 2.8≤a≤4.

Rendering Methods

Chaotic map draws the bifurcation diagram itself. Enabling Stabilize point runs one extra pass before plotting so transient values do not dominate the picture.

Lyapunov plots the average logarithmic derivative of the same recurrence. Values above zero indicate sensitive dependence on initial conditions; values below zero indicate stable attraction.

Options

Seed is the initial x0 value. A seed between 0 and 1 is usually the most useful for the classic logistic map.
