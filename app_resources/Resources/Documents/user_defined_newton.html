User Defined Newton-Raphson

A Newton fractal generated from a user-supplied function.

Formula

\(z_{n+1}=z_n-\frac{f(z_n)}{f'(z_n)}\), where \(f\) is supplied by the user and wxChaos symbolically compiles \(f'\).

Background

The symbolic compiler derives the derivative, making this mode useful for exploring root basins of custom functions. It generalizes the built-in \(z^3-1\) Newton fractal to arbitrary supported formulas.

wxChaos capabilities

  • Configurable convergence, residual, derivative, root-tolerance, and escape thresholds.
  • Algorithm: convergence test.
