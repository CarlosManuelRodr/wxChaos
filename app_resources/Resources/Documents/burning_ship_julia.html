Burning Ship Julia

A fixed-parameter dynamical-plane view of the Burning Ship formula.

Formula

\(z_{n+1}=(|\operatorname{Re} z_n|+i|\operatorname{Im} z_n|)^2+k\). Each pixel supplies \(z_0\), while \(k\) is fixed for the whole image.

Background

This variant is analogous to a Julia set: instead of drawing the parameter plane, it fixes a Burning Ship parameter and asks which starting values remain bounded.

wxChaos capabilities

  • High-precision rendering, Julia constant editing, and orbit display.
  • Smooth coloring and orbit traps.
  • Algorithms: escape time, Gaussian integer, escape angle, triangle inequality.
