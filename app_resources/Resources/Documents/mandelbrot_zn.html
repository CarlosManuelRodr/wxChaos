Mathematical notes

From \(z^2+c\) to \(z^p+c\)

The classic Mandelbrot set uses \(z_{n+1}=z_n^2+c\) with \(z_0=0\). Mandelbrot Zn changes the exponent: \(z_{n+1}=z_n^p+c\). For integer \(p>2\), the map has stronger rotational symmetry and a different escape speed, but the same bounded-versus-escaping test defines the set.
