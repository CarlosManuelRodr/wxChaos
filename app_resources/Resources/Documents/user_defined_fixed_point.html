What to try first

Start with z = sin(z), z = cos(z), or z = z^2. These connect directly to the fixed-point gallery.

Lower the minimum step only after you know the render is behaving. Strict convergence tests can require more iterations.

Look for basin boundaries. They show where nearly identical starting values settle in different ways.

Mathematical notes

Fixed-point iteration

Given a function \(g\), fixed-point iteration computes \(z_{n+1}=g(z_n)\). A fixed point satisfies \(z=g(z)\). wxChaos treats an orbit as converged when the distance between consecutive values falls below the configured minimum step.

Notas matemáticas

Iteración de punto fijo

Dada una función \(g\), la iteración de punto fijo calcula \(z_{n+1}=g(z_n)\). Un punto fijo satisface \(z=g(z)\). wxChaos considera que una órbita ha convergido cuando la distancia entre dos valores consecutivos cae por debajo del paso mínimo configurado.
