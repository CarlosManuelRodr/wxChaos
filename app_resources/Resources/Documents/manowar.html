Manowar

A quadratic fractal that remembers where it just was.

\(z_0=m_0=c,\quad z_{n+1}=z_n^2+m_n+c,\quad m_{n+1}=z_n\)

Most fractals update only from the current value. Manowar adds a second voice: the previous value returns in the next step, creating a map with inertia.

This fractal was created by Scott Taylor and Lee Skinner for FractInt.

Mathematical notes

The extra state variable

wxChaos starts both state values at the selected parameter: \(z_0=m_0=c\). It then uses \(z_{n+1}=z_n^2+m_n+c\), where \(m_n\) stores the previous value of \(z\). After each update, the old \(z_n\) becomes the next memory value. This makes the system second-order: to know what happens next, you need the present and the immediate past.

Notas matemáticas

La variable de estado adicional

wxChaos comienza ambos valores de estado en el parámetro seleccionado: \(z_0=m_0=c\). Después usa \(z_{n+1}=z_n^2+m_n+c\), donde \(m_n\) almacena el valor anterior de \(z\). Tras cada actualización, el antiguo \(z_n\) se convierte en el siguiente valor de memoria. Esto hace que el sistema sea de segundo orden: para saber qué ocurrirá después, se necesitan el presente y el pasado inmediato.
