Mandelbrot Set

The classical connectedness map for quadratic complex dynamics.

Formula

\(z_{0}=0,\quad z_{n+1}=z_n^2+c\). Each screen point is a complex parameter \(c\). wxChaos colors \(c\) by the first iteration where \(|z_n|>2\), or marks it inside when the orbit stays bounded for the chosen iteration limit.

Relationship with Julia sets

The Mandelbrot set is a map of the quadratic Julia family. For each parameter \(c\), the map \(f_c(z)=z^2+c\) has its own Julia set in the \(z\)-plane. The point \(c\) belongs to the Mandelbrot set exactly when that Julia set is connected. In practice, the main window lets you browse parameter space while Julia mode shows the dynamical plane for the selected parameter.

Background

Gaston Julia and Pierre Fatou studied iteration of rational functions in the early twentieth century, mostly without the benefit of computer graphics. Their work asked how repeated application of a complex function divides the plane into stable and chaotic behavior. Benoit Mandelbrot later used computer visualization to study the connectedness locus of the quadratic family, giving a visible shape to that older theory and helping establish fractal geometry as a language for rough natural forms.
