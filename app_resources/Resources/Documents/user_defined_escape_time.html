User Defined Escape Time

A custom complex recurrence entered by the user.

Formula

The formula is supplied through the user formula dialog. It is evaluated as an escape-time recurrence, usually assigning the next value of \(z\) from \(z\), \(c\), and any constants the parser supports.

Background

This mode turns wxChaos into a small laboratory for escape-time formulas without requiring a recompile. It is useful for trying Mandelbrot-like, Julia-like, or entirely personal recurrences.

wxChaos capabilities

  • Formula parsing through muParserX.
  • Configurable bailout and Julia-style mode from the formula dialog.
  • Algorithm: escape time.
