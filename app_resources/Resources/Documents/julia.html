Julia Set

A fixed-parameter view of the same quadratic family that produces the Mandelbrot set.

Formula

\(z_{n+1}=z_n^2+k\). Each pixel supplies \(z_0\); the constant \(k\) is fixed for the whole image.

Background

Julia sets are named after Gaston Julia, who studied iteration of rational functions in the early twentieth century. The Mandelbrot set can be read as a map of which quadratic Julia sets are connected.

wxChaos capabilities

  • High precision and fast perturbation rendering.
  • Orbit display, smooth coloring, orbit traps, and Julia constant editing from the main view.
  • Algorithms: escape time, Gaussian integer, escape angle, triangle inequality.
