Julia Set

The dynamical-plane companion to a single Mandelbrot parameter.

Formula

\(z_{n+1}=z_n^2+k\). Each pixel supplies \(z_0\); the constant \(k\) is fixed for the whole image. A point is inside when its orbit remains bounded.

Relationship with Mandelbrot

The Mandelbrot set is the atlas for this family. Each point \(k\) in the Mandelbrot set corresponds to a connected quadratic Julia set; parameters outside it produce disconnected Julia dust. In wxChaos, the main Mandelbrot view chooses the parameter and Julia mode opens the matching dynamical plane.

Background

Gaston Julia and Pierre Fatou studied what happens when complex functions are repeatedly applied. Their work was motivated by the classification of stable and unstable behavior in rational maps, decades before computers made the boundaries visible. Julia sets are those boundaries: the places where nearby starting points can have very different futures.
