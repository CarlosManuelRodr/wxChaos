Julia Sets

If the Mandelbrot set is an atlas, then the Julia set is one country seen up close.

\(z_{n+1}=z_n^2+k\)

A Julia set fixes \(k\) and asks what happens to every possible starting point \(z_0\). Some choices make connected sets. Others scatter into islands.

A good first visit

Open the Fractal → Enter Julia constant menu and experiment with different parameter values. Notice how even small changes can completely transform the Julia set into a different world.

Open the Mandelbrot page and toggle Julia mode from there. Move the Mandelbrot selector and watch the Julia set respond like a live specimen. Can you see the relationship between the Mandelbrot set and the Julia set?

Try orbit display near a boundary point. The orbit is the hidden choreography behind the visible lace.

Mathematical notes

Why the Mandelbrot set predicts Julia shapes

For \(f_k(z)=z^2+k\), the filled Julia set contains starting values whose orbits remain bounded. The Mandelbrot set records the parameters \(k\) for which the critical orbit starting at \(0\) remains bounded. For quadratic maps, that critical orbit determines whether the Julia set is connected.

Plano dinámico

Conjuntos de Julia

Si el conjunto de Mandelbrot es un atlas, entonces un conjunto de Julia es uno de sus países visto de cerca.

\(z_{n+1}=z_n^2+k\)

Un conjunto de Julia fija \(k\) y pregunta qué ocurre con cada posible punto inicial \(z_0\). Algunos valores producen conjuntos conectados. Otros se dispersan en islas.

Una buena primera visita

Abre el menú Fractal → Introducir constante de Julia y experimenta con distintos valores del parámetro. Observa cómo incluso cambios muy pequeños pueden transformar por completo el conjunto de Julia en un mundo diferente.

Abre la página del conjunto de Mandelbrot y activa desde ahí el modo Julia. Mueve el selector de Mandelbrot y observa cómo el conjunto de Julia responde como si fuera un espécimen vivo. ¿Puedes ver la relación entre el conjunto de Mandelbrot y el conjunto de Julia?

Prueba la visualización de la órbita cerca de un punto de la frontera. La órbita es la coreografía oculta detrás del lienzo visible.

Notas matemáticas

Por qué el conjunto de Mandelbrot predice las formas de los conjuntos de Julia

Para \(f_k(z)=z^2+k\), el conjunto de Julia lleno contiene los valores iniciales cuyas órbitas permanecen acotadas. El conjunto de Mandelbrot registra los parámetros \(k\) para los cuales la órbita crítica que comienza en \(0\) permanece acotada. En los mapas cuadráticos, esa órbita crítica determina si el conjunto de Julia es conexo.
