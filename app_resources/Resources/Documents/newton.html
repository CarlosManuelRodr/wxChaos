Newton Fractal

A map showing which guesses find which root.

Newton's method is usually taught as a numerical tool. In the complex plane it becomes a territorial map: every starting point is colored by the solution it eventually finds, and the borders between territories are fractal.

Mathematical notes

Newton's method as a dynamical system

For a function \(f\), Newton's method repeatedly applies \(z_{n+1}=z_n-f(z_n)/f'(z_n)\). A root becomes an attracting destination, and each pixel belongs to the basin of the root reached from that starting point. wxChaos' built-in Newton fractal uses a historical cubic-style Newton iteration and colors convergence behavior.
