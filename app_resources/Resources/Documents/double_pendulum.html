Double Pendulum

A parameter-space image of a chaotic mechanical system.

Formula

Each pixel supplies initial angles \((\theta_1,\theta_2)\). wxChaos starts with zero angular velocity, integrates the coupled double-pendulum equations, and colors the point by how long the simulated motion avoids the selected bailout tests.

Options

\(\theta_1\) Bailout
Enables a stop condition for the first pendulum angle.
\(\theta_2\) Bailout
Enables a stop condition for the second pendulum angle.
Value
The angle threshold, in radians. The default \(\pi\) means the angle has crossed a half-turn boundary.
DeltaT
The simulation time step. Smaller values are slower but reduce numerical drift.
m1, m2
The masses of the upper and lower pendulum bobs. Changing them changes how energy moves between the two arms.
Longitude
The pendulum arm length used by the equations.
Gravity
The gravitational acceleration parameter.
Relative angles
When enabled, bailout tests compare \(\theta_1\) and \(\theta_2\) against their initial pixel angles. When disabled, they compare against absolute zero-centered angles.
Runge-Kutta
Uses a fourth-order Runge-Kutta style integration step instead of the simpler Euler step. It is usually more stable for the same DeltaT, but more expensive.

Background

A double pendulum is deterministic, but it is highly sensitive to initial conditions. Two nearby angle pairs can remain close for a while and then diverge dramatically. Rendering the initial-angle plane as an escape map turns that sensitivity into a fractal boundary.

wxChaos capabilities

  • Configurable masses, length, gravity, timestep, bailout conditions, relative-angle mode, and Runge-Kutta mode.
  • Orbit drawing for the simulated angular trajectory.
  • Algorithms: escape time and escape angle.
