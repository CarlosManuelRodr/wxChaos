Fractal Dimension

A way to ask how much space a shape really occupies.

The dimension calculator estimates box-counting dimension, also called Minkowski-Bouligand dimension. It is useful when a shape is too wrinkled, branching, or self-similar to be described well as only a line, an area, or a volume.

Why fractals can have non-integer dimensions

Ordinary geometry has clean categories: a line is one-dimensional, a filled square or disk is two-dimensional, and a cube is three-dimensional. Fractals often live between those categories. They may be made of curves, yet fold, branch, and repeat so much detail that they occupy space faster than a smooth curve but not as completely as a filled surface.

A line or a circle's outline has dimension 1 because doubling the measurement resolution roughly doubles the number of small ruler pieces needed to cover it. A filled square has dimension 2 because halving the box size makes the number of required boxes grow about four times. A fractal boundary can grow by an in-between factor, and that in-between growth is what fractal dimension tries to measure.

The box-counting idea

Imagine placing a grid of square boxes over the fractal. Count how many boxes touch the set. Then use a finer grid and count again. If the box size is \(\varepsilon\), let \(N(\varepsilon)\) be the number of boxes that contain part of the set.

The dimension is estimated from how quickly \(N(\varepsilon)\) grows as \(\varepsilon\) becomes smaller. Fast growth means the set fills space more densely. Slow growth means it behaves more like a simple curve or a sparse collection of points.

The fractal dimension is estimated by the following formula that compares the number of occupied boxes compared to the size of the grid.

\[ \dim_\text{box}(S) := \lim_{\varepsilon \to 0} \frac {\log N(\varepsilon)}{\log(1/\varepsilon)} = - \lim_{\varepsilon \to 0} \frac {\log N(\varepsilon)}{\log(\varepsilon)} \]

In practice no program can take the limit all the way to zero. So wxChaos renders the fractal at a finite resolution, tries several grid sizes, and estimates the slope of the log-log relationship.

What the plot means

The calculator compares several values of \(\varepsilon\). For each one it counts occupied boxes, then fits the trend between scale and count. A value near 1 means the visible set behaves like a curve. A value near 2 means it fills the image area more like a surface. Many fractals land somewhere between those values.

Treat the result as an estimate, not a perfect identity. It depends on render size, chosen viewport, iteration count, the box sizes you ask it to test, and how much detail is visible at that resolution.

Using the Dimension Calculator in wxChaos

Choose a fractal and region

Select the fractal, then set the horizontal and vertical bounds for the square area you want to measure. The preview shows the region that will be rendered.

Fractals with a known-good calculator preset automatically load suitable bounds, iterations, division function, and image size when selected. These values remain editable if you want to experiment with a different measurement.

Scripted fractals appear here only when their author explicitly enables dimension calculation and supplies a tested preset in the script's Configure() function.

Set render detail

Pick the image size and iteration count. Higher values can reveal more structure, but they take longer to render and count.

If the finest requested boxes approach the size of individual pixels, wxChaos displays a warning. Increase the square image size or reduce the upper division limit before relying on the estimate.

Choose box divisions

Use the function tab to generate box divisions, or enter a list manually. These divisions decide which box sizes are tested.

Calculate and read the result

Press Calculate. wxChaos builds an occupancy map from raster set points or vector primitives, counts occupied boxes for each selected scale, logs progress, and reports an estimated box-counting dimension. If the value is 1.45, for example, the visible set is more space-filling than a smooth curve but still far from filling the whole square region.

Dimensión fractal

Una forma de preguntar cuánto espacio ocupa realmente una figura.

La calculadora de dimensión estima la dimensión por conteo de cajas, también llamada dimensión de Minkowski-Bouligand. Es útil cuando una figura es demasiado irregular, ramificada o autosimilar para describirla adecuadamente solo como una línea, un área o un volumen.

Por qué los fractales pueden tener dimensiones no enteras

La geometría ordinaria tiene categorías bien definidas: una línea es unidimensional, un cuadrado o un disco relleno es bidimensional y un cubo es tridimensional. Los fractales suelen encontrarse entre esas categorías. Pueden estar formados por curvas y, aun así, plegarse, ramificarse y repetir tantos detalles que ocupan el espacio más rápidamente que una curva suave, aunque no tan completamente como una superficie rellena.

Una línea o el contorno de un círculo tienen dimensión 1 porque duplicar la resolución de medición duplica aproximadamente el número de pequeños segmentos necesarios para cubrirlos. Un cuadrado relleno tiene dimensión 2 porque reducir a la mitad el tamaño de las cajas hace que el número de cajas necesarias aumente aproximadamente cuatro veces. Una frontera fractal puede crecer según un factor intermedio, y ese crecimiento intermedio es lo que la dimensión fractal intenta medir.

La idea del conteo de cajas

Imagina que colocas una cuadrícula de cajas sobre el fractal. Cuenta cuántas cajas tocan el conjunto. Después usa una cuadrícula más fina y vuelve a contar. Si el tamaño de las cajas es \(\varepsilon\), sea \(N(\varepsilon)\) el número de cajas que contienen alguna parte del conjunto.

La dimensión se estima a partir de la rapidez con la que \(N(\varepsilon)\) crece cuando \(\varepsilon\) disminuye. Un crecimiento rápido significa que el conjunto llena el espacio con mayor densidad. Un crecimiento lento significa que se comporta más como una curva simple o como una colección dispersa de puntos.

La dimensión fractal se estima mediante la siguiente fórmula, que compara el número de cajas ocupadas con el tamaño de la cuadrícula.

\[ \dim_\text{box}(S) := \lim_{\varepsilon \to 0} \frac {\log N(\varepsilon)}{\log(1/\varepsilon)} = - \lim_{\varepsilon \to 0} \frac {\log N(\varepsilon)}{\log(\varepsilon)} \]

En la práctica, ningún programa puede llevar el límite completamente hasta cero. Por ello, wxChaos renderiza el fractal con una resolución finita, prueba varios tamaños de cuadrícula y estima la pendiente de la relación logarítmica entre ambas variables.

Qué significa la gráfica

La calculadora compara varios valores de \(\varepsilon\). Para cada uno cuenta las cajas ocupadas y después ajusta la tendencia entre la escala y el conteo. Un valor cercano a 1 significa que el conjunto visible se comporta como una curva. Un valor cercano a 2 significa que llena el área de la imagen de manera más parecida a una superficie. Muchos fractales se encuentran en algún punto entre ambos valores.

Considera el resultado como una estimación, no como una identidad exacta. Depende del tamaño del renderizado, la región seleccionada, el número de iteraciones, los tamaños de caja que se prueben y la cantidad de detalle visible con esa resolución.

Cómo usar la calculadora de dimensión en wxChaos

Elige un fractal y una región

Selecciona el fractal y después establece los límites horizontales y verticales del área cuadrada que quieres medir. La vista previa muestra la región que se renderizará.

Los fractales que tienen una configuración recomendada para la calculadora cargan automáticamente límites, iteraciones, función de divisiones y tamaño de imagen adecuados. Estos valores siguen siendo editables si quieres experimentar con otra medición.

Los fractales programados solo aparecen aquí cuando su autor activa explícitamente el cálculo de dimensión y proporciona una configuración comprobada en la función Configure().

Configura el detalle del renderizado

Elige el tamaño de la imagen y el número de iteraciones. Los valores más altos pueden revelar más estructura, pero requieren más tiempo para renderizar y realizar el conteo.

Si las cajas más finas solicitadas se aproximan al tamaño de los píxeles individuales, wxChaos muestra una advertencia. Aumenta el tamaño de la imagen cuadrada o reduce el límite superior de divisiones antes de confiar en la estimación.

Elige las divisiones de las cajas

Usa la pestaña de función para generar las divisiones de las cajas o introduce una lista manualmente. Estas divisiones determinan qué tamaños de caja se pondrán a prueba.

Calcula e interpreta el resultado

Presiona Calcular. wxChaos construye un mapa de ocupación a partir de los puntos del conjunto ráster o de las primitivas vectoriales, cuenta las cajas ocupadas para cada escala seleccionada, registra el progreso y reporta una estimación de la dimensión por conteo de cajas. Si el valor es 1.45, por ejemplo, el conjunto visible llena más espacio que una curva suave, pero todavía está lejos de llenar toda la región cuadrada.
